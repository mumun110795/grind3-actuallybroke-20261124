## About this entry

Most error dialogs hide behind "something went wrong" because admitting the real cause is embarrassing. This entry does the opposite: it names a failure every user has lived through — an update that was supposed to fix things deleting the config file the app needs to start — tells the user the one action that actually helps (reinstall), and lands the sting in the confession at the end: the fix was the bug. It is specific instead of vague, honest about who is at fault, and short enough to read once, laugh, and repeat to a colleague word for word.
